"Колекція міні ігор" Проєкт виконала Тимохина Ксенія. Мета проєкту: створити на Java програму, яка дозволяє користувачу пограти у дві класичні настiльні гри. Функції: у грі наявні наступні ігри:

1)Хрестики - нолики. Гравець і комп'ютер по черзі "обирають" місце для встановлення своєї позначки. Наприкінці гри виводиться відповідне повідомлення.

2)Камінь, ножиці, папір. Гравець обирає один з трьох варіантів ходу, комп'ютер обирає рандомно. На екран виводиться відповідне повідомлення.
