"Колекція міні ігор"
Проєкт виконала Тимохина Ксенія.
Мета проєкту: створити на Java програму, яка дозволяє користувачу пограти в три класичні гри з використанням консолі.
Функції: у грі наявні наступні ігри:
*Морський бій. У міні грі є два режими:
1) Гравець виступає у ролі "мисливця" за кораблями комп'ютера. Він вводить у консоль координати, доки всі кораблі супротивника не будуть знищенні. Після цього на екран буде виведено повідомлення з кількістю затрачених ходів.
2) Гравець "ховає" свої кораблі (вводить координати через консоль), а комп'ютер їх "шукає". Коли всі кораблі знищено, на екран виводиться повідомлення з кількістю затрачених ходів.
* Хрестики - нолики. Гравець і комп'ютер по черзі "обирають" місце для встановлення своєї позначки (гравець через консоль, а комп'ютер - рандомно). Наприкінці гри виводиться відповідне повідомлення.
*Камінь, ножиці, папір. Гравець вводить через консоль один з трьох варіантів ходу, комп'ютер обирає рандомно. На екран виводиться відповідне повідомлення.
